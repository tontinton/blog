# tontinton.com

Zola blog (theme: `themes/apollo` submodule). Content in `content/`, templates/overrides in `templates/`,
static files in `static/` (copied verbatim, e.g. `static/tenochtitlan/`).

Voxel art pieces live in `static/voxel/<slug>/` and share the library in `static/voxel/lib/`.
For anything voxel-related use the `voxel-art` skill / read `voxel/README.md`.
